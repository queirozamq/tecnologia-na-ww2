# História da Computação na Segunda Guerra Mundial

Projeto web desenvolvido com o objetivo de apresentar a evolução da computação durante a Segunda Guerra Mundial, destacando máquinas, pesquisadores e acontecimentos que contribuíram para o desenvolvimento dos computadores modernos.

O site aborda como as necessidades militares impulsionaram avanços tecnológicos entre 1939 e 1950, explorando sistemas como Colossus, ENIAC e ACE, além da instalação de computação de Los Alamos.

## Sobre o projeto

O conteúdo é apresentado em formato de artigo histórico e dividido em seções interativas, permitindo que o visitante conheça os principais acontecimentos e teste seus conhecimentos sobre o assunto.

O projeto também relaciona os desafios enfrentados pelos primeiros computadores com conceitos importantes da engenharia de software, como programação, depuração, concorrência e armazenamento de instruções na memória.

## Funcionalidades

- **Página inicial:** apresentação e contextualização histórica do projeto.
- **Artigo histórico:** conteúdo dividido em cinco seções sobre os principais acontecimentos da computação durante a guerra.
- **Principais nomes:** apresentação de personalidades importantes, como Alan Turing, Tommy Flowers e Grace Hopper.
- **Quiz interativo:** cinco perguntas de múltipla escolha, com correção automática, explicações das respostas, barra de progresso e pontuação final.
- **Referências bibliográficas:** listagem das fontes utilizadas na elaboração do conteúdo.
- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.

## Como executar

Não é necessário instalar dependências ou configurar um ambiente de desenvolvimento.

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado o projeto compactado.
3. Abra a pasta do projeto.
4. Execute o arquivo `site_sobre_a_ww2.html` em um navegador.

**Importante:** mantenha todos os arquivos na mesma pasta para garantir o funcionamento correto das imagens, estilos e funcionalidades.
